# 🤖 AI-Powered Pitch Trainer (Adaptive Learning)

## 🎓 Academic Project Overview

This project was developed as a **Semester Project** during my **4th year** of **Informatics Engineering** at **Antioch Syrian University (ASU)**. It demonstrates the practical application of Digital Signal Processing (DSP) and automated feedback loops in music education technology.

## 📝 Description

**AI-Pitch-Trainer** is an intelligent, real-time audio analysis tool designed to help musicians and vocalists improve their pitch accuracy. By leveraging advanced pitch detection algorithms, the system provides instantaneous visual and auditory feedback, adapting its difficulty level based on the user's performance.

## 🛡️ Key Technical Features

- **Real-time Signal Processing:** Uses the `aubio` library for high-accuracy pitch detection and `pyaudio` for low-latency audio streaming.
- **Adaptive Learning Logic:** The system features a dynamic tolerance mechanism that tightens or loosens the "Success Zone" based on user mastery.
- **Noise Gate Implementation:** Utilizes RMS (Root Mean Square) volume thresholds to filter out background noise.
- **Musical Intelligence:** Integrated with `music21` to handle complex scales, keys, and musical notation.

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Core Libraries:** `pygame` (Interface), `pyaudio` (Sound Input), `aubio` (DSP), `music21` (Music Theory), `numpy` (Math).
